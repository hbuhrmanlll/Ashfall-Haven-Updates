# Ashfall Haven: app downloads

Android app downloads and update info for **Ashfall Haven** by Third Heaven Studios.

- `AshfallHaven.apk`: the latest signed Android app. On your phone, open
  https://github.com/hbuhrmanlll/Ashfall-Haven-Updates/raw/main/AshfallHaven.apk and install it.
- `version.json`: the latest version number. The game's *Check for updates* reads it.

This repo is published automatically by the game's build. It holds no game source and no keys.
